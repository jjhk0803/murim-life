# 무림인생

강호에 한 번 태어나 한 해씩 선택하며 살아 보는 무협 인생 시뮬레이션.
백년맹약이 끝나는 시대, 당신의 선택이 강호의 역사를 가른다.

**▶ 플레이: https://jjhk0803.github.io/murim-life/** (깃허브 페이지를 켠 뒤 주소를 바꿔 주세요)

- 설치 없이 브라우저에서 바로 실행된다. 휴대폰·PC 모두 된다.
- 진행은 자동 저장된다(그 브라우저에만). 역대 기록 상위 10개와 역천점도 남는다.
- 그림은 선택이다. NovelAI 토큰이 있으면 인물 초상과 사건 장면을 그릴 수 있다.

## 파일

## 깃허브 페이지로 공개하기
1. 새 **Public** 저장소(예: `murim-life`)를 만들고 이 폴더의 파일을 저장소 맨 위에 올린다.
2. 저장소 **Settings → Pages → Source: Deploy from a branch → `main` / `/ (root)` → Save**.
3. 1~2분 뒤 `https://<아이디>.github.io/<저장소>/`가 열린다. 위 플레이 링크를 그 주소로 고친다.

## 그림 (NovelAI, 선택)
게임을 시작하기 전(첫 화면 오른쪽 위) 또는 게임 중 위쪽의 **설정**에서 정한다.

- **기본 그림**: 저장소 `img/` 폴더에 개발자가 넣어 둔 그림이 모든 플레이어의 기본 그림이 된다.
- **플레이어는 자기 그림체로 덮어쓴다**: 그림체를 고르고 그리거나 넣은 그림은 그 브라우저에만 저장되며 기본 그림보다 먼저 나온다. 전부 자기 그림체로 바꾸고 싶으면 설정에서 '게임에 들어 있는 기본 그림을 쓴다'를 끄고 '빈 칸 모두 그리기'를 쓴다.
- **개발자 도구**: 그림 관리 목록의 '개발자 도구'를 열면 저장소용 묶음 받기가 나온다.

- **토큰**: novelai.net 로그인 → 설정(톱니) → Account → Get Persistent API Token. 토큰은 플레이하는 사람의 브라우저에만 저장되고 저장소에는 들어가지 않는다. **저장소 파일에 토큰을 적어 올리지 말 것.**
- **주인공 초상과 나이**: 초상 프롬프트에 겉나이가 들어간다(어림 → 소년 → 약관 → 청년 → 장년 → 중년 → 노년 → 고령). 단계가 바뀌면 지금 초상을 레퍼런스로 삼아 얼굴은 그대로 두고 나이만 바꿔 다시 그린다(설정에서 끌 수 있다). 환골탈태하면 겉모습이 스무 살 남짓으로 돌아가 그 뒤로 천천히 늙고, 현경 이상은 반로환동으로 늙음이 늦어진다. 초상 프롬프트를 직접 고쳐 두었으면 그대로 두고 알려만 준다.
- **그리는 곳**: 위쪽 초상 칸, 강호 탭의 인물록, 사건 카드의 '장면 그리기'. 프롬프트(영어 태그)를 고쳐 그리거나 가진 그림 파일을 넣을 수 있다.
- **저장**: 그림은 브라우저 IndexedDB에 저장된다. 사건 장면은 한 번 그리면 모든 인생에서 다시 쓴다.
- **비용**: 그림마다 구독 등급에 따라 Anlas가 들 수 있다. 자동 그리기는 기본으로 꺼져 있다.

### 그림체와 그림 관리
설정 → **그림체 · 그림 관리**에서 한다.
- **그림체 탭**: 미리 만든 그림체(무협 일러스트·수묵화·공필화·애니메이션·무협 웹툰·반실사 유화)를 고르거나 태그를 직접 고친다. 인물·장면·지도에만 붙일 태그와 네거티브도 정한다.
- **지도·인물·사건 탭**: 그림이 들어갈 모든 칸이 보인다. 칸을 누르면 그림체가 붙은 최종 프롬프트와 네거티브를 복사할 수 있다. NovelAI 웹 등 다른 곳에서 그린 뒤 **파일에서 넣기**로 넣으면 된다. 토큰이 없어도 된다.
- **여러 장 넣기**: 파일 이름을 규칙대로 맞추면 한 번에 제자리로 들어간다.

| 칸 | 파일 이름 (여러 장 넣기) | 저장소 경로 |
|---|---|---|
| 중원 지도 | `map.png` | `img/map.png` |
| 지역 | `reg_henan.png` | `img/reg/henan.png` |
| 인물 (스탠딩) | `st_seorin.png` | `img/st/seorin.png` |
| 사건 장면 | `ev_sage.png` | `img/ev/sage.png` |

칸의 정확한 이름은 그 칸의 창 아래쪽에 나온다.

### 내 그림체 저장
그림 관리 → 그림체 탭에서 태그를 고친 뒤 이름을 붙여 **지금 그림체 저장**을 누르면 그림체 태그·인물/장면/지도 태그·네거티브가 함께 저장된다. 저장한 이름을 누르면 그 그림체로 바로 바뀐다(최대 20개, ×를 두 번 눌러 지운다).

### 골라서 다시 그리기
각 탭의 **골라서 다시 그리기**를 누르면 칸을 눌러 여러 장을 고를 수 있다(이 탭 모두 고르기 · 그림 있는 칸만). **고른 n장 다시 그리기**를 한 번 더 눌러 확인하면 차례로 다시 그린다. 다시 그리면 바로 전 그림이 남아서, 그 칸의 그리기 창에서 **이전 그림으로**를 누르면 되돌릴 수 있다(한 번 더 누르면 새 그림으로).

### 한꺼번에 그리기
지도·인물·사건 탭의 **빈 칸 모두 그리기**를 누르면(한 번 더 눌러 확인) 그 탭의 빈 칸을 NovelAI로 하나씩 차례로 그린다. 내 그림이나 저장소 그림이 있는 칸은 건너뛴다. 창을 닫아도 계속 그리고, **멈추기**로 언제든 멈춘다. 토큰·Anlas 오류가 나면 저절로 멈춘다. 장마다 Anlas가 들 수 있다.

### 스탠딩과 배경 지우기
- **인물** 탭은 인물의 스탠딩(카우보이 샷)이다. 인물록의 얼굴 칸에도 이 그림을 쓴다. 예전 `npc_` 파일 이름은 스탠딩 칸으로 들어간다. 사건에 그 인물이 나오면(인연 사건이거나 본문에 이름이 나오면) 사건 장면 그림 위에 — 없으면 지금 있는 지역 그림 위에 — 이름표와 함께 서서 나온다.
- 스탠딩 프롬프트에는 `cowboy shot, standing, white background`가 붙는다. 흰 배경은 배경 지우기를 위해 남겨 두었다. 그리거나 넣으면 배경을 자동으로 지운다(인물 탭에서 끌 수 있다). 이미 투명한 PNG는 그대로 둔다.
- **처음부터 투명하게**: 스탠딩은 NovelAI V5의 투명 배경 생성(`transparent background`)으로 그린다. 배경을 지울 필요가 없다. 모델 설정이 V4.5여도 스탠딩만 V5로 그린다. 인물 탭에서 끌 수 있고, 투명 생성이 실패하면 흰 배경으로 다시 그려 자동으로 지운다.
- **자동 배경 지우기**(흰 배경 그림): 가챠 게임 메이커와 같은 방식. 테두리 띠의 중앙값으로 배경색을 잡고, 테두리에서 이어진 배경과 발밑 그림자를 지운다. 팔과 몸 사이처럼 갇힌 곳은 색이 고르게 배경과 같을 때만 지워 음영 있는 흰 옷은 남긴다. 떠 있는 티끌을 치우고, 경계 2~3픽셀은 반투명하게 다듬으며 배경색을 빼낸다.
- **NovelAI로 지우기**: 편집기에서 NovelAI의 배경 제거를 쓸 수 있다(Anlas가 든다, 생성 한 장의 약 3배). 결과를 손으로 더 고칠 수 있다.
- 인물 칸의 **배경 지우기**는 포토샵처럼 손으로 고치는 편집기다.
  - **마술봉**: 누른 곳과 비슷한 색을 지운다. 범위를 넓히거나 좁힐 수 있고, '이어진 곳만'을 끄면 그림 전체에서 비슷한 색을 지운다. 팔과 몸 사이·머리카락 틈처럼 갇힌 흰 부분은 하나씩 누른다. 지운 둘레는 반투명하게 다듬어 흰 테두리를 줄인다.
  - **지우개 / 복원 붓**: 칠해서 지우거나, 너무 지운 곳을 원본으로 되살린다. 붓 크기를 바꿀 수 있다.
  - **이동·확대(1×·2×·4×)**, **보기(바둑판·검정·초록)**: 남은 흰 테두리는 검정·초록 배경에서 잘 보인다.
  - **되돌리기**(8번까지), **자동으로 지우기**, **원본으로**, **이대로 쓰기**.
  - 원본과 손본 결과는 브라우저에 남겨 두어 다음에 이어서 고칠 수 있다(저장소용 묶음에는 들어가지 않는다).
- 배경 지우기는 브라우저 안에서 바로 하며 외부로 보내지 않는다. 복잡한 배경은 잘 지워지지 않으니, 그럴 땐 다른 도구로 지운 투명 PNG를 넣는다.

### 깃허브에 바로 올리기 (추천)
그림 관리 → 지도·인물·사건 탭 → **개발자 도구**에서, 내 그림 전부를 저장소 `img` 폴더에 **커밋 하나로** 올린다. 바뀐 그림만 올라가고 `img/index.json`도 함께 고쳐진다. 백 장이 넘어도 된다(웹 업로드의 100개 제한이 없다).
1. GitHub → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token.
2. Repository access: **Only select repositories** → 이 저장소 하나. Permissions → Repository permissions → **Contents: Read and write**. 기한은 원하는 만큼.
3. 게임의 개발자 도구에 저장소(`아이디/이름`, github.io에서 열면 저절로 채워진다), 브랜치(`main`), 토큰을 넣고 **깃허브에 바로 올리기**.
4. 1~3분 뒤 깃허브 페이지에 반영된다.

토큰은 그 브라우저(localStorage)에만 저장되고 저장소 파일에는 들어가지 않는다. 다른 사람이 쓰는 기기에서는 넣지 말 것. 토큰이 새면 GitHub에서 바로 지우면 된다.

### 저장소에 그림 넣기 (손으로 올릴 때)
1. 그림 관리의 지도·인물·사건 탭에서 **저장소용 묶음 받기**를 누르면 `murim-img.zip`이 내려받아진다. 안에는 `img/` 폴더와 `img/index.json`(그림 목록)이 들어 있다. 'WebP로 줄여 담기'를 켜 두면 용량이 크게 준다.
2. 압축을 풀어 나온 `img` 폴더를 저장소 맨 위(`index.html` 옆)에 올린다. 이미 `img`가 있으면 덮어쓴다.
3. 이제 그 주소로 들어오는 사람은 모두 그 그림을 본다. 저장소에 그림이 있는 칸은 '자동으로 그리기'를 켜도 새로 뽑지 않는다.

- 그림을 고르는 순서: **이 브라우저의 내 그림 → 저장소 그림 → 없음**. 내 그림을 지우면 저장소 그림으로 돌아간다.
- `index.json` 없이 위 표의 경로에 `.png`만 올려도 찾는다. 다른 확장자(`.webp`, `.jpg`)는 `index.json`에 적혀 있어야 한다.
- 주인공 초상은 인생마다 달라 저장소에서 찾지 않는다.

### 중계 서버 (필요할 때만)
브라우저가 NovelAI에 바로 연결하지 못하면(CORS 오류) 중계 서버가 필요하다.
1. `proxy/worker.js`의 `ALLOW_ORIGIN`을 게임 주소의 앞부분(예: `https://<아이디>.github.io`)으로 바꾼다.
2. [Cloudflare](https://dash.cloudflare.com) → Workers & Pages → Create → Worker → 코드를 붙여 넣고 Deploy. (무료 요금제로 충분하다)
3. 게임 설정의 **중계 서버 주소**에 워커 주소(`https://○○.workers.dev`)를 넣는다.

워커는 NovelAI(`image.novelai.net`)로 가는 요청만, 지정한 주소에서 온 요청만 전달하고 아무것도 저장하지 않는다.

## 세계관과 이야기
백 년 전, 화산 정상에서 천마 혁련 패와 검성 독고 무가 사흘 밤낮을 싸우다 둘 다 사라졌다. 남은 정·사·마는 화산에서 **백년맹약**("백 년 동안 서로의 땅을 넘지 않는다")을 맺었다. 그 백 년이 주인공의 젊은 날에 끝난다.

### 두 갈래의 삶
**무림인 루트**: 문파·세가·사파·마교에 들어 칼로 산다.
- **정파**: 6대 문파(소림·무당·화산·아미·곤륜·개방)와 3대 세가(남궁·당가·팽가), 세외의 북해빙궁.
- **사파**: 흑도 연맹 **사도련** 아래 하오문·녹림맹·장강수로채·살막·귀영루·만화궁. 사도련 회합이 열린다.
- **마교**: 천마신교·혈교.
- 세력 안에서 강해지면 **정파제일인 / 사파제일인 / 마교제일인**을 가리는 자리에 선다(초절정·명성 150 이상). 그 위에서 가장 강한 자가 화산논검에서 **천하제일인**이 된다. 소속이 있으면 먼저 그 세력의 제일인이 되어야 한다.
- 입문 시험은 세력마다 다르다. 소림의 천 개의 계단, 무당의 흑백의 물음, 화산의 지는 매화와 장공잔도, 곤륜의 설산의 밤, 개방의 깨진 동냥 그릇, 아미의 금정의 종, 남궁의 족보 앞, 팽가의 무쇠 도, 당가의 세 개의 잔과 독사의 상자, 하오문의 객잔의 귀, 마교의 혈투장과 강자존, 빙궁의 얼음 호수, 장강수로채의 물살. 늦게 들어가는 길도 녹림의 투명장, 수로채의 여울, 귀영루의 목숨 하나, 만화궁의 미혼곡, 소림의 삼 년의 물처럼 저마다 다르다.

**일반인 루트**: 열다섯까지 문파에 들지 못하면 밥벌이를 정한다. 생업을 가지면 무림인 사건 대신 생업 사건이 일어나고, 강호의 큰일(맹약, 정마대전, 천마)은 소문으로 들려와 생업에 영향을 준다. '나' 화면에 **가업** 탭이 생기고, 위 이름표에 전투력 대신 신분과 은자가 나온다.
- **객잔**: 간판에 직접 이름을 짓는다. 점소이 → 객잔 주인 → 이름난 객잔 주인 → 천하객잔의 주인. 자릿세와 뒷배(정파·하오문), 간판 요리(걸왕이 찾아오기도), 정보상 겸업, 칼부림 중재, 피난민, 맞은편 객잔과의 요리 대결. 주방의 늙은 숙수가 전설의 도왕이라 반근팔량도를 배워 객잔을 잇거나 강호로 나갈 수 있고, 손님이 남긴 은자로 무관에 들어가 무림인이 될 수도 있다.
- **대장간**: 견습 → 대장장이 → 명장 → 신장. 조직의 전속 대장장이(당가·팽가·녹림·수로채·남궁·소림)가 되거나 홀로 일한다. 의뢰인의 광석으로 칼을 벼리고, 명검 계보(용천·추수·단심·월영)에 번호를 붙인다. 당가의 폭우이화침, 운철로 벼리는 신병이기, 대장간 키우기(흙벽 대장간 → 천공로), 내가 벼린 칼의 소식, 전쟁의 주문. 손수 벼린 칼을 들고 무림인이 될 수도 있다.
- **의원**: 견습 → 의원 → 명의 → 약왕 → 의선 → 신의. 제 몸으로 독을 시험해 **독수(毒手)**를 얻으면 의술과 항독이 그대로 전투력이 되어 무뢰배를 독으로 제압하고 영수를 잠재운다. 독에 몸을 맡기면 **독마**, 독을 다스리면 **독의**가 된다. 조용한 약(독살 의뢰), 치료비 대신 배우는 무공, 약방의 제자, 벼랑 끝의 영초도 있다. 역병, 문 앞의 무림인, 독마의 독, 황궁의 부름, 대환단, 천수의 비밀, 전장의 의원. 사천당가나 독마·약왕의 제자도 '독과 약은 한 몸'에서 의원의 길로 갈 수 있다.
- 무림인도 마흔이 넘으면 칼을 내려놓고 객잔·대장간·의원을 열 수 있고, 수명이 다해 갈 때 **신의**를 찾아 수명을 늘릴 수 있다.

### 정·사·마
- **정파**: 바르고 아름답게. 하산하는 날 장문인의 당부, 아이들을 팔던 명문 장로 천의검 백 무상의 처단, 무림맹 대전에서 어린 마교 포로의 목숨, 은자 한 푼 없는 어촌을 지키는 이름 없는 협행, 꽃 아래 사형제들의 검무.
- **사파**: 흑도답게, 낭만 있게. 취검 낭 일소와 칼·술·춤, 참수를 앞둔 형제를 위해 옥문을 깨기, 빗속 다리 위의 결투(진 쪽이 술을 산다), 사도련주의 배신자 처리 명령, 장강용왕의 누선 잔치.
- **마교**: 음흉하게, 간계로. 부교주 음 사구의 국화와 반역, 군사 귀모의 바둑(정파끼리 싸우게 하는 계략), 피의 서열전, 요마녀의 부탁, 광마 단 광천. 정파·무소속은 잔칫날 마교의 독을 막는다.

### 인물
- **정파**: 소림방장 현오 대사, 무당장문 청진자, 매화검존 운학, 아미장문 정혜 사태, 운룡검 운중학, 만천수 당 천위(당가주), 벽력도왕 팽 무적(팽가주), 검왕 남궁 진천(남궁가주), 걸왕 노취옹(개방 방주), 청송검 진 송학, 천의검 백 무상(타락한 장로), 검선·불존·검후·정천신산.
- **사파**: 사도련주 위 패천, 만사통 은 삼낭(하오문), 장강용왕 갈 천호, 취검 낭 일소, 단비도 철 무심, 녹림왕·천면귀·무영귀·암제·백화마후.
- **마교**: 천마, 천변마군 음 사구(부교주), 귀모 사공 염(군사), 요마녀 요 화령, 검마·혈마·독마.
- **그 밖**: 광마 단 광천, 신의 편 작란, 천하설서 구 노인, 철벽표두 용 맹, 무황, 빙후, 신장 구야 철.
- 세력의 제일인 자리에서는 그 세력의 최강자(정파: 검왕·매화검존·벽력도왕…, 사파: 사도련주·녹림왕·장강용왕…, 마교: 부교주·검마·혈마…)와 겨룬다.

### 새로 만난 사람들
문파마다 얼굴을 더했다. 모두 대화(답에 따라 이어지는 말), 내력, 찾아올 때 하는 말, 소개해 주는 사람이 있다.
- **정파**: 만두나한 공명(소림, 계율보다 만두), 철계도장 현무진인(무당 계율원, 이십 년 전 파문한 제자를 기다린다), 매화검수 조 연(화산, 청운에게 백 번 져도 백한 번째 검을 든다), 창궁이검 남궁 호(검왕의 아우), 백독노조 당 노태군(당가의 할머니), 묵도서생 팽 사호(도 대신 붓을 든 팽가 셋째), 아미철면 자운 사태(소소의 사저)
- **사파**: 황포채주 황보 웅(녹림을 군대로 만들려는 서열 둘째), 저잣거리 쥐 길수(하오문 꼬마 정보원), 일곱째 그림자 칠영(살막을 나가고 싶은 자객), 늙은 사공 수동 노인(전대 장강수로채 대채주), 만화무희 백련(화 연의 벗)
- **마교**: 수라대주 강혼(죽은 부하 이백의 이름을 외운다), 혈교성녀 홍의(혈천대법의 제물로 길러진 소녀)
- **세외·강호**: 빙궁 유모 한빙 노파, 떠돌이 화공 연생(내 얼굴을 그리고 세월 뒤에 다시 그린다), 철면포두 염 철수(무림인을 싫어하는 관부 포두), 취선주모 곽 주모(걸왕의 옛사랑)
- **이어지는 이야기**: 칠영이 살막을 빠져나가도록 돕기, 혈교 제단에서 홍의 구하기, 검왕과 아우의 사십 년 만의 비무, 포두와 함께 납치범 잡기. 황보 웅의 편에 설지 녹림왕에게 알릴지도 고른다.
- 조 연·백련·홍의(남자 주인공), 팽 사호·칠영(여자 주인공)과는 인연이 될 수도 있다. 지난번에 더한 인연 열두 명에게도 첫 대화가 생겼다.

### 인물지와 관계
- **강호 인물지**(강호 → 인물): 모든 인물을 사마·정파·사파·마교·세외·후기지수로 나눠 보여 준다. 이름을 누르면 스탠딩 그림, 소속, 보이는 경지, 관계와 호감, **내력**, 그리고 그 사람과 함께한 일을 나이순으로 적은 **나와의 일**이 나온다(만나지 못한 사람은 소문만).
- **사마(四魔)**: 광마 단 광천(세상보다 한 뼘 더 미친 자), 독마 당 무진(독에 삼켜진 자), 검마 사마 율(검에 미친 자), 요마 요 화령(마음을 홀리는 자). 해마다 하룻밤 이름 없는 주루에 모이는 '사마' 사건에서 누구 곁에 앉을지 고른다.
- **찾아오는 사람**: 호감 40이 넘은 인물이 찾아와 생업과 사문에 맞게 돕는다. 객잔이면 단골을 데려오고, 대장간이면 광석을, 의원이면 약초를 두고 간다. 같은 사문이면 공헌, 장문인이면 무공을 가르친다.
- **달려온 사람**: 크게 다쳤거나 원한이 쌓이면 호감 50이 넘은 인물이 달려와 돌보고 원수를 물린다.
- **소개**: 믿는 사람이 다른 사람을 데려온다(걸왕 → 광마, 검왕 → 서린, 매화검존 → 청운, 천마 → 혁련 하 등).
- **두 사람 사이**: 아는 두 사람(검왕과 검마, 당가주와 독마…)이 칼을 겨누면 한쪽 편을 들거나 술로 말린다.
- **마지막 술잔**: 가까운 노고수가 세상을 떠나며 마지막 잔을 청하고, 생업과 사문에 맞는 것을 남긴다.
- **적이 된 연인**: 맹약이 깨지거나 정마대전이 벌어지면, 정파와 마교로 갈라선 연인과의 이야기는 끊긴다. 그러다 '적이 된 연인'이 찾아온다. 사문을 버리고 함께 떠나거나, 가사약으로 함께 죽은 척하거나(어긋나면 비극), 사문의 명을 따르거나, 명을 거부해 몰래 만난다.
- **수라장**: 호감이 높은 인연 둘 이상이 한날 한자리에 모인다. 한 사람의 손을 잡거나, 모두 소중하다고 말하거나(명성·용모·구력이 높으면 한집에 살게 된다), 창문으로 도망친다. 함께 살게 되면 '시끄러운 집' 이야기가 이어진다.

### 인물과의 대화
강호를 다니다(또는 객잔·대장간·의원에 찾아온) 위 인물들 서른 명 남짓을 만나면 말을 걸어온다. 같은 문파 사람과 그 지역 사람을 더 자주 만난다. 답을 고르면 상대가 다시 말을 잇고, 답에 따라 호감·수양·도덕·무공이 바뀐다. 호감이 쌓이면 그 인물의 속 깊은 두 번째 이야기가 열린다.
- **같은 사문 사람**: 사문에 들면 그 사문 사람들은 이미 아는 얼굴이 된다(정체를 숨긴 혁련 하는 빼고). 첫 대화도 낯선 사람과의 만남이 아니라 사문 어른·사형제와의 자리로 바뀐다(빙궁 사람이면 객잔이 아니라 한옥전에서 궁주를 만나는 식). 마교도는 혁련 하를 총단 담장 위의 소교주로 만난다. 수장의 호칭은 사문에 맞게 장문인·가주·방주·궁주·교주로 부른다.
- **수장이 되면**: 살아 있는 수장 인물은 전대 수장으로 물러나고, 사문 사람들이 당신을 수장으로 대한다. 천마나 혈마가 살아 있으면 원로 회의로는 교주가 될 수 없다.
- **처지에 따라 달라지는 말**: 같은 편이면 같은 편답게(“교의 형제여”, “같은 백도끼리 반갑소”), 제일인·장문인이 되면 그에 맞게 대한다. 정파와 마교는 원수라, 마교 주인공에게 정파 인물이 다정하게 말을 걸지 않는다. 원수 진영 인물과는 호감 40이 넘어야 평소 대화가 열리고, 그때도 남의 눈을 피해 만난다. 정파와 사파, 사파와 마교는 비꼬고 경계한다.
- **깃발이 다른 사람**: 길에서 다른 진영 인물과 마주친다. 칼을 뽑거나, 말로 맞받아치거나, 깃발 너머의 사람으로 대해 적이면서 벗이 되는 길을 연다.

### 천하쟁패: 정도천하 · 사도천하 · 마도천하
- 강호 탭의 **천하의 판도**에 정파·사파·마교가 천하를 얼마나 쥐었는지 나온다. 사문에서 높이 오르고 이름을 떨치면, 그리고 **세력 다툼**(선봉·계책·회유)에서 이기면 내 쪽이 커진다. 마교 부활·무림맹·정마대전·천마의 몰락·수장들의 죽음도 판도를 흔든다. 세월은 판도를 조금씩 제자리로 되돌린다.
- 한쪽이 55%를 넘으면 그쪽의 천하가 온다. 마교면 “마도천하! 만마앙복!”, 정파면 “정도천하! 협의장존!”, 사파면 “사도천하! 의리불멸!”. 내가 그 편이면 단상에 올라 함성을 받거나(제일인·교주라면 칭호), 패자를 돌아보거나, 그 그늘을 들여다본다. 다른 편이면 같은 날이 장례가 된다. 칼을 들고 맞서거나, 숨어서 불씨를 지키거나, 살길을 찾는다. 그 시대가 이어지는 동안 '천하의 나날'이 찾아오고, 45% 아래로 떨어지면 시대가 저문다.

### 대화 연출 (미연시)
사건과 결과는 미연시 화면으로 나온다. 배경 그림(사건 장면, 인연 배경, 없으면 지금 있는 지역 그림)이 화면을 가득 채우고, 그 위에 장면의 인물들이 선다(스탠딩이 있는 사람만, 최대 셋, 말하는 사람만 밝게). 아래 대사창에 지문과 대사가 한 줄씩 나오고, 대사에는 이름표(별호 · 이름)가 붙는다. 주인공의 대사는 이름표만 붙고 모습은 나오지 않는다.

- 화면 아무 데나 누르거나 Enter를 치면 다음 줄
- 위쪽 줄: 나이 · 사건 이름, 장면 그리기, ◀ 이전, **기록**(지난 대사), **자동**(글 길이에 맞춰 저절로 넘김, 켠 상태는 기억), **넘기기**
- 줄을 넘길 때는 글·이름표·인물 강조만 바뀌고 배경과 인물 그림은 다시 불러오지 않는다. 인물 그림의 아랫부분은 대사창 뒤로 들어가며 흐려진다.
- 한 사건 안에서는 무작위로 고르는 인사말이나 장소도 처음 정한 그대로 간다(그릴 때마다 글이 바뀌어 대사가 처음으로 돌아가던 문제를 고쳤다).
- 마지막 줄이 나오면 배경이 어두워지고 **선택지가 위쪽에 뜬다**. 결과 화면에서는 대사창 아래에 바뀐 수치가, 위쪽에 ‘한 해를 보낸다’가 뜬다.
- 설정의 ‘대화를 미연시처럼 한 줄씩 보여 준다’를 끄면 예전 두루마리 카드로 돌아간다.

화자는 대사 앞뒤 문장에서 찾는다(‘소소가 웃었다’, ‘그녀가 말했다’, ‘당신이 말했다’ 등). `이름: “대사”` 꼴의 줄은 그 사람의 대사가 된다.

### 인물끼리
아는 두 사람이 함께 있는 장면에 끼어든다. 화산 사형매의 백열세 번째 비무, 아미 사저의 잔소리, 남궁 숙부와 조카, 남궁 남매, 걸왕과 주모의 외상값, 만화궁의 이름 없는 춤, 빙궁 부엌의 국, 하오문의 문고리, 당가 독장의 행방, 녹림은 무엇인가. 두 사람을 모두 알고, 둘 중 하나와 호감이 20 이상이고, 둘 다 살아 있고 적이 아닐 때 한 번씩 열린다. 누구 편을 드느냐에 따라 두 사람의 호감이 갈린다.

### 연애와 혼인
- **인연이 될 사람**: 이야기가 있는 인연(서린·소소·화 연·소혜 / 현·청운·제갈 운·무결, 혁련 하) 말고도 문파마다, 생업마다 인연이 될 사람이 있다.
  - 남자 주인공: 빙설선자 설 은하(빙궁, 은발), 혈봉 위지 연화(마교 성녀), 강남 꾀꼬리 소령(하오문), 곤륜설화 운 설아(곤륜), 향의 백 의향(약방 의녀), 국숫집 딸 주 소화, 요마 요 화령, 천면귀 묘영, 빙후 설한월
  - 여자 주인공: 빙검 설 한(빙궁, 은발), 흑풍 묵 야(마교 호법), 강남 제비 낭 청(하오문), 후개 홍 칠(개방), 곤륜일학 운 해(곤륜), 대장간 청년 석 돌, 청송검 진 송학, 취검 낭 일소
  - 같은 사문 사람은 입문할 때부터 알고 지낸다. 객잔·대장간·의원을 하면 손님으로 찾아온다.
- **만나고 가까워지기**: '눈길이 머문 사람'으로 처음 만나고, '마음이 기우는 날'(비 오는 처마, 다친 사람, 등불 축제, 무뢰배, 서찰, 새벽 수련, 별똥별, 장터)에 가까워진다. 혼기가 차면 **중매쟁이**가 강호 명부에서 인연을 찾아 준다.
- **올해의 나날에서 직접 고른다**: '인연을 찾아 나선다'를 고르면 지금 단계에 맞는 일이 온다. 새 사람을 만나거나, 마음에 둔 사람과 가까워지거나, 때가 되면 '○○에게 마음을 전하러 간다'로 바뀐다. 연인이 생기면 '연인과 시간을 보낸다'가 된다.
- **고백 → 연인**: 호감 35쯤부터 고백할 수 있다(용모·구력과 그 사람이 좋아하는 것이 도움이 된다). 연인이 되면 원소절 연등, 칠석의 지붕, 새벽 비무, 처마 밑의 비, 장날의 비녀, 서호 뱃놀이, 첫 입맞춤, 질투, 다툼과 화해, 집안 어른 뵙기, **둘이 가는 길**(등을 맞대고 산적과 싸우기) 같은 날들이 이어진다.
- **혼담 → 혼례**: 연인과 세 번쯤 함께한 날을 보내고 호감이 70을 넘으면 혼담이 온다. 검왕의 시험은 세 번째에는 끈기로도 통과한다. 혼례는 성대하게, 조촐하게, 달 아래 단둘이 중에서 고르고, 인물마다 맹세가 다르다. 혼인한 뒤에는 '함께 사는 날'이 이어진다. 늦은 나이에도 혼인할 수 있다.
- 연애를 쫓으면 대개 20대 후반~40대에 혼인한다. 연애에 신경 쓰지 않으면 혼인은 드물다.

### 병기와 광물
- **병기 종류**를 알아보기 쉽게: 검(곧은 양날)·도(휜 외날)·권갑(주먹에 끼는)·창·봉·암기(비도·비침)·금(소리로 싸운다)·철선(쇠 부채). 나 탭과 풀무 화면에 종류마다 그림(없으면 선 그림 아이콘)이 붙는다. 주먹 병기 이름이 '○○수갑'으로 나오던 것을 '○○권갑'으로 고쳤다(전에 얻은 것도 고쳐진다).
- **인연 배경**: 인연 이야기와 연애 사건에서는 그 사람에게 어울리는 배경(서린은 남궁세가 후원, 소소는 금정 절벽, 설 은하는 빙궁 서고…) 위에 스탠딩이 선다. 그림 관리 → 인연 배경 탭에서 사람마다 그린다(`bg_seorin.png`처럼 넣어도 된다). 배경이 없으면 지금 있는 고장의 그림이 뒤에 깔린다.
- **병기 그림**: 그림 관리 → 병기 탭에서 종류마다 그린다(`wp_sword.png`, `wp_gauntlet.png`, `wp_fan.png`처럼 넣어도 된다). 병기 한 자루만 어두운 돌바닥 위에 대각선으로 놓인 제품 사진처럼 그린다(그림체 태그는 붙이지 않고, 여러 개·받침대·칼집·사람은 네거티브로 막는다).
- **광물 열세 가지**: 정철·현철·한철·화린석·독철·운석에 청강석(검·도)·오금(봉·창·권갑)·묵철(암기)·백옥(금·철선)·혈옥(도·권갑)·만년한철·자금이 더해졌다. 고장마다 나는 광물이 다르다(화산·남궁은 청강석, 숭산·광동은 오금, 무당·강남은 백옥, 동정호는 묵철, 청해는 혈옥, 북해는 드물게 만년한철).
- **광물의 쓰임**:
  - 새 병기를 벼린다. 광물과 **잘 맞는 병기**면 최대 등급이 하나 오르고, 광물의 결이 병기에 깃든다.
  - **가진 병기 다듬기**: 풀무 화면에서 가진 병기에 광물을 덧대어 등급을 하나 올린다(광물마다 한계가 있다). 결이 없던 병기에는 광물의 결이 깃든다.
  - **품거나 삼키기**: 한철·만년한철은 음기 +20, 화린석은 양기 +20(음양이 맞아야 쓰는 무공에), 혈옥은 내공 +6년(대신 도덕↓·살기↑), 백옥은 수양 +4.
  - **팔기**: 시세대로 판다. 대장장이는 30% 비싸게 판다.

### 결말과 CG
- 살아온 길에 따라 결말이 스무 가지로 갈린다: 우화등선, 혈신, 천하제일인, 마도·정도·사도천하, 시끄러운 집, 엇갈린 약속, 모든 것을 버리고, 한 문파의 주인, 객잔의 등불, 쇠의 노래, 인술, 대마두, 대협, 은거, 요절, 칼끝의 최후, 범부의 일생, 강호의 나그네.
- 결말마다 **수묵 CG**가 있고, 혼인한 사람이 있으면 그 사람과의 CG가 하나 더 나온다. 그림이 없으면 먹으로 그린 원(圓)과 결말의 글자가 대신한다. CG 칸은 NovelAI로 그리면 수묵 태그(ink wash, sumi-e, monochrome…)가 붙고, 넣은 그림도 먹빛(흑백)으로 보인다.
- **인연 CG**(혼인한 사람과의 CG)는 다르다. 인물은 그림체 탭에서 정한 그림체와 인물 태그로 색을 입혀 그리고, 배경만 먹으로 남긴다(partially colored, spot color, greyscale background…). 넣은 그림도 흑백으로 바꾸지 않고 그대로 보인다. 예전에 그린 인연 CG는 다시 그려야 이렇게 바뀐다.
- 인연 CG를 그릴 때는 그 사람의 **스탠딩을 캐릭터 레퍼런스**로 넣어 얼굴·머리·옷을 스탠딩과 맞춘다(가챠 게임 메이커의 스탠딩 레퍼런스와 같은 방식). 레퍼런스는 NovelAI V4.5에서만 되므로 이때는 V4.5 Full로 그리고, Anlas가 더 들 수 있다. 스탠딩이 없으면 레퍼런스 없이 그린다. 켜고 끄는 곳은 두 군데다: CG란에서 ‘함께’ CG를 눌러 여는 그리기 창의 **스탠딩 레퍼런스** 버튼, 그리고 설정의 ‘캐릭터 레퍼런스’ 칸.
- 혼인한 사람의 CG는 젊은 날의 모습으로, 주인공은 1인칭 시점(손만 보이게)으로 그려 얼굴이 나오지 않는다. 결말 CG도 주인공은 뒷모습으로 그린다.
- **결말과 CG** 모음: 태어나기 전 화면과 생을 마친 화면에서 연다. 본 결말과 함께한 사람의 CG가 모이고, 못 본 것은 ？로 남는다. 그림 관리에도 CG 탭이 생겼다(`cg_ascend.png`, `cg_love_soso.png`처럼 이름을 맞추면 여러 장 넣기도 된다).

### 일대기
- 생을 마치면 그 삶이 한 권의 책으로 묶인다. 세로로 쓴 제목이 붙은 표지와 함께, 별호와 두드러진 능력으로 '○○록'이라는 이름이 붙는다(예: 별호 무신에 경공이 높으면 무신풍신록).
- AI 이야기꾼을 켜 두었으면 **AI 사관에게 일대기를 맡긴다**를 누른다. AI가 이 삶의 기록(소속·경지·별호·인연·남긴 자취·강호사·연대기)을 돌아보고 이 사람에게 맞는 제목(한자 표기 포함)과 한 줄 평, 4~6장으로 나눈 일대기, 선택들에 대한 평가를 쓴다. 제목은 역대의 삶 목록에도 남는다.

### AI 이야기꾼 (선택)
- 설정의 **AI 이야기꾼**에서 쓸 AI를 고르고 키를 넣으면, AI가 지금까지의 삶(소속·경지·인연·천하의 판도·최근 일)을 읽고 새 사건을 지어 준다. 올해의 나날에서 'AI가 짓는 이야기를 펼친다'를 고르고 바라는 이야기를 적을 수 있다(비워 두면 AI가 고른다). '저절로 끼어드는 AI 사건'을 켜면 한 해에 15%·30% 확률로 미리 지어 둔 사건이 끼어든다.
- 고를 수 있는 AI (가챠 게임 메이커와 같은 방식):
  - **Claude (Anthropic)**: Opus 5.5(기본) · Sonnet 5.5 · Haiku 5.5. 키는 platform.claude.com → API Keys.
  - **Gemini (Google)**: gemini-2.5-flash(기본) · pro · flash-lite. 키는 aistudio.google.com → Get API key. 무료 사용량이 있다.
  - **OpenAI 방식**: OpenRouter · OpenAI · DeepSeek · Ollama 클라우드 버튼으로 주소를 채운다. 그 밖에 OpenAI 방식으로 부르는 API라면 주소(`/chat/completions` 앞부분까지)와 모델 이름을 직접 넣으면 된다.
  - 세 가지 키는 따로 저장되어, AI를 바꿔도 다른 키가 지워지지 않는다.
- 브라우저에서 바로 연결되지 않는 서비스(CORS)는 '중계 서버를 거쳐 보낸다'를 켠다. 이때 중계 서버를 저장소의 최신 `proxy/worker.js`로 바꿔 둬야 한다(Gemini·OpenRouter·OpenAI·DeepSeek·Ollama 클라우드·Anthropic 주소를 허용한다. 다른 서비스는 `ALLOW_HOSTS`에 호스트를 더한다).
- AI가 지은 사건도 처지를 지킨다. 원수 진영 인물이 주인공을 칭찬하지 않게, 등장 인물은 게임 명부에 있는 인물만 쓰게 했다. 선택지의 수치 변화는 게임이 정한 범위 안으로 잘리고, AI 사건으로는 죽지 않는다. Claude는 정해진 JSON 형식으로 답하게 하고, 다른 AI는 형식을 글로 알려 준 뒤 답에서 JSON을 골라 읽는다(못 읽으면 한 번 더 요청한다).
- 키는 그 브라우저에만 저장된다. 저장소 파일이나 깃허브에 올리는 그림에는 들어가지 않는다. **저장소에 키를 적어 올리지 말 것.**

### 심법
- 주 심법은 한 해 내공과 음양 말고도 **저마다의 쓰임**이 있다: 수련 속도, 전투력, 받는 피해, 수명, 벽을 깰 확률, 체력. 문파 심법도 문파마다 다르다(소림 역근경은 호신과 수명, 무당 태청심법은 수명과 벽, 화산 자하신공은 수련, 하오문 은형심법은 수련, 녹림 패천공은 체력, 천마신공은 위력…). 나 탭 → 무공·병기에서 효과를 볼 수 있다.
- **새 심법 열네 가지**: 청명심공(수명) · 귀원신공(체력) · 소요유심공(수련) · 월하심결(수련) · 장생결(수명 +15) · 태청강기(호신) · 금강부동심법(호신·수명) · 파벽심결(벽 +12%p) · 뇌정신공(위력) · 무상심법(위력·수련) · 구양진경(극양·체력) · 현빙진경(극음·호신) · 만류귀종심법(조화·수련·벽) · 혈하마경(내공 1.9년·위력, 대신 수명 −10).
- **심법의 기연**: 무너진 도관의 석벽, 죽어 가는 노인의 책, 고서점, 동굴의 백골, 경매장, 꿈속의 도인, 숨겨 준 사내의 목숨값으로 심법을 얻는다. 주 심법으로 삼거나, 익혀만 두거나, 사문에 바치거나 판다. 높은 성의 심법일수록 드물고, 기연이 높을수록 잘 나온다.
- **주 심법 바꾸기**: 익힌 심법은 나 탭에서 언제든 '주 심법으로'를 눌러 바꿀 수 있다. 바꾸면 쌓인 내공의 1할이 흩어진다.
- **심법 창안**: 무공 창안 화면에서 '심법'을 고르면, 익힌 결 두세 개와 바라는 것(내공·수련·수명·벽·호신·위력·체력)을 골라 나만의 심법을 만든다. 음과 양을 함께 고르면 조화형이 된다. 경지에 따라 3~5성, 쌓인 내공이 많을수록 잘 엮이며, 실패하면 기혈이 역류해 다치고 내공이 조금 흩어진다.

### 수련의 쓰임새
- **무공 수련**: 주무기 숙련과 깨달음.
- **운기조식**: 내공을 두 배로 쌓고, 경지의 벽을 깰 성공률을 올린다.
- **음양을 조율한다**: 음양을 가운데로 모은다. 음과 양을 함께 쓰는 무공·조화형 심법·음양지체는 음양이 고를수록 전투력이 최대 20% 오른다.
- **경공**: 전투력에 더 크게 들어가고, 받는 피해를 최대 20% 줄인다.
- **참선**: 수양과 함께 때때로 깨달음이 온다. 수양 75·초절정 이상이면 참오 끝에 **선도**에 눈떠 현경에서도 우화등선할 수 있다. 수양은 벽을 깰 성공률도 올린다.
- **글 읽기**: 학문·구력·심계와 함께 무학이 늘어 수련이 빨라진다.

### 집중 사건
한 해 안에 선택이 이어진다: 입문 시험(줄 서기 → 몸의 시험 → 마음의 시험), 첫 강호행(행선지 → 첫 만남 → 첫 의뢰), 용봉지회(입장 → 예선 → 결승, 매 판 전술 선택), 화산 회의, 정마대전, 화산논검.

### 외전
화산신룡 매 청운(꺾인 신룡 → 외팔의 매화 또는 독비마검), 천마의 자식 혁련 하, 사형제, 의형제, 점소이, 대장장이, 살막, 천하제일미와의 인연.

### 인연 (호감도에 따라 열리는 개인 이야기)
연애할 수 있는 인물 서른한 명 모두에게 세 장짜리 이야기가 있다. 호감이 18·42·65에 이르면 한 장씩 열린다(인물록에 '이야기 n/3'). 장마다 지문과 대사가 3000자 넘게 이어지고, 인물과 다섯 번 넘게 말을 주고받는다. 선택지는 장마다 두세 개이고, 고른 것에 따라 결과 이야기도 다르다.

- **남자 주인공**: 남궁 서린, 연 소소, 화 연, 당 소혜, 설 은하, 위지 연화, 소령, 운 설아, 백 의향, 주 소화, 요 화령, 묘영, 빙후 설한월, 조 연, 백련, 홍의, 혁련 하
- **여자 주인공**: 남궁 현, 매 청운, 제갈 운, 당 무결, 설 한, 묵 야, 낭 청, 홍 칠, 운 해, 석 돌, 진 송학, 낭 일소, 팽 사호, 칠영, 혁련 하

이야기에는 그 인물 곁의 사람들도 나온다(빙후와 은하, 은 삼낭과 소령, 걸왕과 홍 칠, 남궁 진천과 서린 등). 끝까지 함께하면 신혼의 날과 백발의 날이 오고, 혼인 CG의 글도 그 이야기에서 나온다.

### 선배의 한마디 · 가족 · 굽히지 않는 마음
- 걸왕·검선·불존·무황·늙은 사공·나무꾼 같은 강호의 선배가 지나가듯 한마디를 남긴다. 마음에 새긴 말은 묘비의 **가슴에 남은 말**에 남는다.
- 어머니의 손, 아버지의 등, 집에서 온 편지, 부모의 임종. 고아로 태어났다면 이름 없는 무덤을 찾아간다.
- 권세 앞에서 무릎을 꿇지 않으면 선비들이 시를 짓는다. 지키지 못한 아이 앞에서 한 맹세는 수십 년 뒤 돌아온다.
- 생을 마치면 그 삶을 한 줄로 새긴 묘비명이 남는다.

### 경지의 벽과 깨달음
- 삼류~절정까지는 수련·내공·영약으로 쌓은 깨달음만 차면 오른다. **초절정부터는 벽마다 깨달음 조각이 있어야 한다**: 초절정 1 · 화경 2 · 현경 3 · 생사경 4.
- 깨달음 조각: 고수의 한마디(선배의 말을 마음에 새긴다), 상승 무공(4성 이상), 절세 무공(5성), 특별한 심법(4성 이상이거나 내공이 빨리 쌓이는 심법), 깊은 내공(벽마다 30·60·120·180년), 영약의 기운(큰 영약), 생사의 고비(죽기 직전까지 몰렸다 산다), 나보다 강한 자를 넘음(높은 경지의 상대를 이긴다), 환골탈태, 잃어 본 마음, 스스로 지은 무공, 깊은 수양(60), 벽을 바라본 시간(벽 앞에서 참오), 마인이면 피로 다진 살기. 새로 얻은 조각은 연대기에 '깨달음 · ○○'으로 남는다.
- **타고난 것**: 천무지체·천살성은 필요한 조각이 둘 적고 벽을 깰 확률도 높다. 공령지체·선골·음양지체·검골·천안은 하나 적다. 오성 9 이상도 하나 적다. 타고난 것 없이 오성 4 이하인 **범재**는 초절정부터 하나 더 필요하고, 화경부터는 깰 확률이 반으로 준다. 생사경은 누구든 생사의 고비를 넘겨 봐야 한다.
- 조각이 모자라면 벽 사건이 세 해에 한 번만 온다. 그때는 억지로 칠 수도 있지만(범재는 몇 %, 크게 다친다), 벽 앞에 앉아 벽을 바라보면 오성에 따라 조각 하나를 얻을 수 있다(벽마다 한 번).
- **마도의 경지**: 마공을 주 심법으로 삼거나 마교에 있으면 절정부터 **입마 · 성마 · 극마 · 탈마 · 천마지경**이라 부른다. 극마에는 살기 40 이상, 탈마에는 마성을 다스릴 마음(수양 40 이상이거나 특별한 심법)이 따로 있어야 한다.
- 경지는 쌓인 수련에 따라 **초입 · 소성 · 대성 · 정점**으로 나뉘어 보인다(예: 절정 대성). 정점은 벽 앞에 섰다는 뜻이다.

### 나이에 맞는 삶
- 젊은 날의 사건(첫눈에 반함·고백·연적, 객잔 시비, 산적, 도전장, 선배의 훈계 등)은 사건마다 정해진 나이를 넘기면 열다섯 해에 걸쳐 드물어진다. 새 인연 이야기의 첫 장은 쉰이 넘으면 열리지 않는다(이미 시작한 이야기는 이어진다).
- 화경 이상의 고수에게는 잡배의 시비·산적·암습이 드물고, 현경 이상은 노환(멎지 않는 기침)을 앓지 않는다.
- 쉰 무렵부터는 노년의 사건이 잦아진다: **후배의 청**(한 수를 청하는 젊은이), **젊은 도전자**, **원로의 자리**(두 문파의 다툼을 판가름), **설서인의 이야기**(부풀려진 내 전설), **손주**, **굳어 가는 손**(화경 아래), **늙지 않는 사람**(현경 이상이나 환골탈태로 젊어진 몸), **늙은 원수**, **마을 아이들**, **천하의 자문**(생사경·현경 원로), **태상장로**, **남기는 말**, **다시 오는 봄**, **몰라보는 사람**(젊어진 얼굴 때문에 애송이 취급을 받는다).
- AI 이야기꾼도 주인공의 나이 단계와 겉나이를 받아, 노년에는 노선배·원로로 대하는 이야기를 짓는다.

## 시스템 요약
- 경지 9단계(범인~생사경), 초절정부터는 깨달음이 있어야 벽을 넘는다. 길에서 이긴 적수는 다시 길을 막지 않고, 두 사람의 원한 다툼도 한 번만 마주친다. 두 단계 차이면 승부가 되지 않는다. 상대가 실력을 숨기면 심계·경지로 꿰뚫기 전까지 전투력이 낮게 보인다.
- 조직: 정파(남궁세가·사천당가·하북팽가 / 소림·무당·화산·아미·곤륜·개방), 사파·사도련(녹림맹·하오문·장강수로채 / 귀영루·만화궁·살막), 마교(천마신교·혈교), 세외(북해빙궁).
